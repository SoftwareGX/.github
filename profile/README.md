# SoftwareGX

Software für den deutschen Mittelstand: lokal, nachvollziehbar, ohne Raten.

## TableGX

> *Wer seine Zahlen kennt, kann handeln.*

TableGX liest gewachsene Excel-Mappen so, wie sie sind, findet, was nicht stimmt, und macht jede
Änderung nachvollziehbar. Sammy, dein digitaler Assistent, beantwortet Fragen in Alltagssprache aus
den eigenen Tabellen, mit der genauen Fundstelle. Ist ein Begriff mehrdeutig, fragt er nach.
Übernommen wird nur, was ein Mensch bestätigt.

- Läuft vollständig im eigenen Firmennetz
- Jede Änderung mit Person, Zeitpunkt und Prüfsumme
- Liest Datum, Betrag und Währung nach festen Normen, statt zu raten
